# Histoire d'Os

## Statut vérifié
prototype - vérifié le 2026-07-15.

## Résumé prudent
Site statique multilingue en développement consacré aux astragales et osselets, avec activités pédagogiques, ressources pour écoles et musées, supports imprimables et jeu 3D.

## Ce qui fonctionne réellement
- Site statique sans build avec parcours français, anglais, allemand et italien
- Quatre dossiers d'activités avec ressources pour la classe et le musée
- Supports HTML imprimables, guides, fiches élèves et corrigés
- Jeu du message secret utilisant Three.js, un modèle GLB et des contrôles clavier

## Ce qui est partiellement implémenté
- Traductions, validation scientifique, accessibilité et vérification d'impression suivies par des rapports et registres
- PDF publics encore identifiés comme WIP tandis que les versions HTML imprimables sont disponibles

## Ce qui est simulé
- Aucun élément vérifié.

## Ce qui n'est pas encore implémenté
- Collection finale de PDF validés pour toutes les activités

## Architecture
- Site statique compatible GitHub Pages, sans framework ni système de build
- Pages multilingues organisées par répertoires et ressources pédagogiques séparées
- Assets locaux, modèle 3D, scripts de navigation et jeu autonome
